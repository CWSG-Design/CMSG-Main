# Image Library

This directory contains the image assets for the CMSG-Main website.

## Directory Structure & Categories

The images are organized into the following categories:

* **`hero/`**: Large banner and background images used in the main hero section of the homepage or other pages.
* **`products/`**: Images of specific products, channel letters, and signage examples.
* **`gallery/`**: General portfolio images, featured projects, and high-quality showcase photos.
* **`team/`**: Photos of team members, staff, or the manufacturing crew.
* **`logos/`**: Company logos, partner logos, client logos, and brand assets.
* **`testimonials/`**: Avatars or profile pictures of clients who have provided testimonials.
* **`shipping/`**: Images related to logistics, crating, shipping, and delivery processes.
* **`installation/`**: Photos showing the installation process, mounting details, or wiring examples.
* **`misc/`**: Miscellaneous images that do not fit into the above categories.

## Usage

When referencing these images in the React components, use the absolute path from the `public` folder. For example:

```jsx
<img src="/images/hero/main-banner.jpg" alt="Main Banner" />
```
