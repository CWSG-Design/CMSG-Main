# CMSG — Canadian Wholesale Sign Group Website

Production website for **Canadian Wholesale Sign Group (CWS)**.

## Stack
- React 19 + TypeScript + Vite 7
- Tailwind CSS 4 + shadcn/ui
- Wouter routing
- Hosted on Manus WebDev

## Pages
- `/` Home
- `/quote` Quote request
- `/shipping` Shipping info
- `/installation` Install guide
- `/installer-sign-up` Installer sign-up

## Dev
```bash
pnpm install && pnpm dev
```
